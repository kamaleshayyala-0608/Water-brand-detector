# Water Brand Detector

A lightweight object detection and classification system for detecting water bottle brands at the edge.

## Folder Structure

- `dataset/`: Contains training/validation data (images and labels).
- `models/`: Stores model weights and configuration files.
- `training/`: Training scripts and hyperparameter configurations.
- `inference/`: Scripts for evaluating models and running predictions.
- `utils/`: Common helpers, dataset parsing, and utility modules.
- `requirements.txt`: Project package dependencies.
- `README.md`: This file.
